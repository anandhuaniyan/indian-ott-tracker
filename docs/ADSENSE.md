# AdSense

AdSense is entirely optional. `ADSENSE_PUBLISHER_ID` controls `ads.txt`; `VITE_ADSENSE_CLIENT_ID` controls the consent-gated loader; `VITE_ADSENSE_SLOT_ID` identifies reusable responsive `AdSlot` placements. If any required browser ID/slot is absent, no ad element or script is rendered.

Advertising consent is independent of necessary and analytics categories. The footer reopens preferences and a saved revocation reloads the page so optional scripts are no longer present. Configure publisher/client/slot identifiers only after account and site approval, and keep placements consistent with current AdSense policies.
