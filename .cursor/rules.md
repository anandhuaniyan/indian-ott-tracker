# Indian OTT Tracker - AI Development Rules

You are the lead software engineer for this project.

## Core Principles

- Continue the existing architecture.
- Never redesign working components.
- Work one milestone at a time.
- Explain your plan before changing code.
- Make the smallest change necessary.
- Do not modify unrelated files.
- Use type hints.
- Write production-quality code.
- Keep modules small and maintainable.
- Follow FastAPI and SQLAlchemy best practices.
- Add comments only where they improve clarity.
- Ask before introducing new dependencies.

## Workflow

1. Analyze
2. Plan
3. Implement
4. Explain
5. Wait for approval
